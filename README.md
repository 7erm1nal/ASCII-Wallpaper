# ASCII Rainy Street — анимированные обои для экрана блокировки (KDE Plasma 6)
Реализовано с помощью Claude.ai
## Архитектура
```
    reference.jpg + masks.psd ──► tools/gen_scene.py ──► contents/ui/scene.js   (статика: слои символов + геометрия)
         ▲        (слои-маски)          ▲                         │
   make_draft_psd.py             tools/geometry.json               ▼
   (черновик масок)          (водостоки, запасная геометрия)  AsciiStreet.qml  ◄── Sim.js    (дождь, брызги, капли, ручейки, блики)
                                                    ▲     ◄── Clock.js  (табло: дата + время)
                                                    │
                                              main.qml (WallpaperItem, настройки из kcfg)
```
* **Офлайн (Python):** картинка → сетка 320×90 символов (ячейка 6×12 px на экране 1920×1080). Символ — по направлению края (`| - / \`) или по
  «детальности»; цвета квантуются в 8 слоёв; пустоту заполняют серые полутона (шумовой дизеринг по тону, 3 слоя `. : ;`). Отдельно: фонари/ореолы (мерцание), кромки для брызг, блики на дороге.
* **Рантайм (QML):** статические слои — N элементов `Text`, построенных один раз. Динамика — 5 слоёв
  (дальний/ближний дождь, брызги, вода, блики). Слои разрежённые: строка собирается только из затронутых клеток — это в ~10 раз быстрее, чем клеить всю сетку (≈5 мс/шаг при плотности 1.0).
* **Данные — в `.js`, а не JSON:** локальный XHR на экране блокировки может быть запрещён, а `import` работает всегда.
* **`AsciiStreet.qml` не зависит от Plasma**, поэтому отлаживается обычным окном без блокировки экрана.

* **Шрифт:** сетка держится на моноширинном шрифте; плагин сам выбирает первый установленный из
  DejaVu Sans Mono / Noto Sans Mono / JetBrains Mono / Hack / Liberation Mono … (или тот, что указан в настройках).
* **Табло:** пиксельные цифры 3×5 (пиксель = `##`, то есть квадрат в ячейках 1:2); если табло ниже — сегментные 3×3, затем обычный текст.

## Маски (PSD)

Конвертер теперь управляется масками: что фонарь, что бордюр, где храм, кипарисы, кромки для дождя, туман, глубина.
**Полный список слоёв и правила — в `tools/MASKS.md`.** Рабочий файл — `tools/masks.psd` (черновик собран автодетектом
и грубыми полигонами; правьте слои в Photoshop). Без `--masks` конвертер сам строит такие же черновые маски.

    python3 tools/make_draft_psd.py tools/reference.jpg -o tools/masks.psd   # пересобрать черновик
    ./tools/regen.sh                                                          # PSD -> scene.js (+ превью)

## Ручьи, ореол, накладка (v3)

* **Ручьи** строятся из слоя `water.flow` (направление — градиент альфы); см. `tools/MASKS.md`, пример — `water.flow.png`.
* **Ореол фонарей** — подкраска существующих символов + мягкая подложка `spill.png` (а не собственные символы).
* **Храм** прорежен и приглушён: `--church-density`, `--church-gain`.
* **Ручная правка фона** — текстовая накладка `tools/overlay/`, см. `tools/OVERLAY.md`.

## Установка

    ./install.sh        # kpackagetool6 -t Plasma/Wallpaper -u/-i plugin/org.user.asciistreet

Параметры → Безопасность → Блокировка экрана → Внешний вид: «Настроить…» → тип обоев «ASCII Rainy Street».
Если плагин не виден в списке — перелогиньтесь (или `kquitapp6 plasmashell && kstart plasmashell`).

## Смена референса

1. Положить новую картинку в `tools/reference.jpg`.
2. Пересобрать черновик масок: `python3 tools/make_draft_psd.py tools/reference.jpg -o tools/masks.psd`.
   Полигоны горы/храма/неба/дороги/растительности в `make_draft_psd.py` заданы под ТЕКУЩИЙ референс — для нового их нужно
   обвести заново (или нарисовать слои в PSD руками).
3. Поправить `tools/geometry.json` (координаты в пикселях референса): `gutters` — ломаные водостоков (от дальнего конца к ближнему), `ground`/`board` — запасная геометрия.
4. `./tools/regen.sh`. Если слишком шумно/тускло: `--edge`, `--gamma`, `--colors`, `--cols`, `--halftone` в `gen_scene.py`.

## Ручки

`Sim.js`: скорости капель, число капель (`0.32*C`, `0.75*C`), вероятность брызг, частота капель с карнизов (`12/с`).
`AsciiStreet.qml`: цвета слоёв дождя, мерцание фонарей, молнии (редко, раз в 20–65 с), `fps`.
Настройки обоев (плотность, ветер, яркость, fps, молнии, локаль табло, шрифт) — `config/main.xml`.
